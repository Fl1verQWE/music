****My task was:****

**UA ver:**

Створи сторінку-каталог “MusicVibe” із картками музичних альбомів.
Умова завдання:
 Кожна картка — обкладинка альбому, виконавець і короткий опис жанру.
 
Інструкція:
Створи HTML і CSS файли, папку images.
У хедері зроби назву “MusicVibe” і меню.
Створи Grid із 9 карток альбомів.
Використай aspect-ratio і object-fit: cover.

Зроби адаптивність:
телефон: 2 колонки,
планшет: 3,
десктоп: 4.

Додай футер з копірайтом “Єгор © 2025”.

Критерії оцінювання:
 
 -зручна сітка;
 
 -чіткі пропорції;
 
 -гарна адаптивність;
 
 -чистота коду;
 
 -візуальна узгодженість.
 
Що має вийти в результаті:
 Каталог музичних альбомів, який виглядає сучасно і не спотворюється при зміні розміру.
 

 **ENG ver:**

 Create a “MusicVibe” catalog page with music album cards.
Task requirements:
Each card should include: album cover, artist, and a short genre description.

Instructions:
Create HTML and CSS files, and a folder named images.
In the header, add the title “MusicVibe” and a navigation menu.
Create a grid with 9 album cards.
Use aspect-ratio and object-fit: cover for the images.

Make it responsive:
Phone: 2 columns,
Tablet: 3 columns,
Desktop: 4 columns.

Add a footer with the copyright: “Єгор © 2025”.

Evaluation criteria:

-User-friendly grid layout;

-Proper proportions;

-Good responsiveness;

-Clean code;

-Visual consistency;

Expected result:
A modern music album catalog that maintains proper proportions and does not distort when resizing.
